## FAQ

### What is XCutors?

XCutors is a curated Windows desktop collection that bundles several popular Roblox executor tools – Volt, Synapse Z, Potassium, and Wave – alongside a universal loader called xcutorsLoader, making it easy to manage and switch between executors from a single interface.

### Which executors are included in the package?

The package ships with four executors: Volt, Synapse Z, Potassium, and Wave. All four are accessible through the xcutorsLoader universal loader.

### Is XCutors free to use?

Yes. XCutors is distributed for free via the official GitHub repository. No premium keys or subscriptions are required to use the loader or the bundled executors.

### What are the minimum system requirements?

You need Windows 10 or Windows 11 (64-bit), at least 4 GB of RAM, a stable internet connection for downloads and updates, and the latest version of Roblox installed.

### How do I update the executors when a new version is released?

Simply launch xcutorsLoader – it automatically checks for updates on startup. If an update is available, you will be prompted to download and install it with a single click.

### Can I load and run my own custom Lua scripts?

Absolutely. You can paste scripts directly into the built-in editor, drag-and-drop .lua files from your computer, or load scripts from a URL. The executor will run any valid Lua script in the current Roblox session.

### Is it safe to run XCutors on my computer?

XCutors only contains tools sourced from well-known and trusted developers in the Roblox scripting community. Always download the package from the official GitHub repository to avoid tampered files. As with any third-party tool, use it responsibly.

### Which versions of Roblox are supported?

XCutors targets the latest stable version of Roblox on Windows. After major Roblox updates, executors may require patches – the auto-update system handles most of these automatically, but occasional manual updates may be needed.

### The loader is failing to attach. What should I do?

First, make sure you are running xcutorsLoader as an administrator. Temporarily disable or whitelist the folder in your anticomponent software, as false positives can block injection. Also confirm that Roblox is fully launched and you are in a game before clicking 'Attach'.

### Can I use XCutors on macOS or Linux?

No. XCutors and all bundled executors are built exclusively for Windows. There is no macOS or Linux version available at this time.
